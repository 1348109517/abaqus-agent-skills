# v0.3.0 Runnable Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a no-dependency, fully synthetic Abaqus workflow audit demo, safe skill installer, contributor metadata, and verified v0.3.0 release experience.

**Architecture:** A small root-level `abaqus_agent_demo` package loads a bounded JSON contract, runs deterministic checks, and renders one canonical result to JSON and Markdown. Thin scripts expose the demo and installer without packaging or third-party dependencies; committed synthetic scenarios and standard-library tests make every public claim reproducible.

**Tech Stack:** Python 3.10+ standard library, `unittest`, JSON, Markdown, GitHub Actions, Citation File Format 1.2.0.

## Global Constraints

- The runnable demo supports Python 3.10 or newer.
- Runtime and tests require no third-party Python packages and no Abaqus installation.
- All scenarios and values are independently created synthetic content.
- The demo does not run Abaqus/CAE, a solver, `abqpy`, `.cae`, `.odb`, or arbitrary `.inp` parsing.
- Static `PASS` never implies solver completion, physical validity, engineering approval, or official SIMULIA support.
- Reports are deterministic and contain no timestamp by default.
- Public files contain no private paths, credentials, customer data, or unpublished research content.
- Installer operations are dry-run by default and never overwrite an existing target.
- Public promotion starts only after a verified tagged release; each external post requires maintainer review of the exact site, account, title, body, links, and images.

```python
# abaqus_agent_demo/contract.py
class ContractError(ValueError):
    pass


def load_contract(path: Path) -> dict[str, Any]:
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, UnicodeError, json.JSONDecodeError) as exc:
        raise ContractError(f"cannot load contract {path}: {exc}") from exc
    if not isinstance(value, dict):
        raise ContractError("contract must be a top-level JSON object")
    return value


def input_digest(path: Path) -> str:
    return hashlib.sha256(path.read_bytes()).hexdigest()
```

```python
def audit_contract(contract: Mapping[str, Any]) -> tuple[Finding, ...]:
    shape_findings = tuple(check_contract_shape(contract))
    if any(item.status != "PASS" for item in shape_findings):
        return shape_findings
    findings: list[Finding] = []
    for check in CHECKS:
        findings.extend(sorted(check(contract), key=lambda item: (item.location, item.code)))
    return tuple(findings)
```

The checks use these exact rules:

| Code | Passing rule | Non-pass status and location | Related skill |
|---|---|---|---|
| `C-CONTRACT-001` | Required list/object keys have the expected JSON types | `REVIEW_REQUIRED` at the missing or invalid key | `abaqus-parametric-project-starter` |
| `C-UNITS-001` | `units.length` and `units.force` are nonempty strings | `WARNING` at the missing unit key | `abaqus-parametric-project-starter` |
| `C-NAME-001` | Names are nonempty and unique inside each declared namespace | `REVIEW_REQUIRED` at `<namespace>.<name>` | `abaqus-shared-naming-manifest-builder` |
| `C-REF-001` | All consumer references resolve to declared regions, steps, surfaces, materials, parts, and outputs | `REVIEW_REQUIRED` at the consumer field | `abaqus-dependency-preflight-validator` |
| `C-STEP-001` | Step orders are unique nonnegative integers and referenced load/BC steps exist | `REVIEW_REQUIRED` at `steps.<name>.order` | `abaqus-step` |
| `C-MESH-001` | Every declared part has one mesh intent with a nonempty element family | `WARNING` at `mesh_intents.<part>` | `abaqus-mesh` |
| `C-OUTPUT-001` | Every `review_intent.requires_outputs` name resolves to an output request | `REVIEW_REQUIRED` at `review_intent.requires_outputs.<name>` | `abaqus-output` |
| `C-EVIDENCE-001` | An approved engineering claim has both solver and physical review marked complete | `REVIEW_REQUIRED` at `evidence.engineering_claim` | `abaqus-output` |

Every satisfied rule emits one aggregate `PASS`. Failed rules emit only their
sorted non-pass findings. Reference namespaces are derived from declared parts,
instances, sets, surfaces, materials, steps, and outputs.

```python
def finding(code, status, message, location, skill, next_action):
    return Finding(code, status, message, location, skill, next_action)


def declared_names(items):
    return {str(item["name"]) for item in items if isinstance(item, Mapping) and item.get("name")}


def check_references(contract):
    model = contract.get("model", {})
    regions = declared_names(model.get("sets", [])) | declared_names(model.get("surfaces", []))
    steps = declared_names(contract.get("steps", []))
    problems = []
    for group_name in ("boundary_conditions", "loads"):
        for item in sorted(contract.get(group_name, []), key=lambda value: str(value.get("name", ""))):
            name = str(item.get("name", "<unnamed>"))
            if item.get("region") not in regions:
                problems.append(finding(
                    "C-REF-001", "REVIEW_REQUIRED",
                    f"{group_name} {name} references undeclared region {item.get('region')!r}.",
                    f"{group_name}.{name}.region",
                    "abaqus-dependency-preflight-validator",
                    "Reconcile the shared naming manifest before model edits or execution.",
                ))
            if item.get("step") not in steps:
                problems.append(finding(
                    "C-REF-001", "REVIEW_REQUIRED",
                    f"{group_name} {name} references undeclared step {item.get('step')!r}.",
                    f"{group_name}.{name}.step",
                    "abaqus-dependency-preflight-validator",
                    "Declare the step or correct the consumer reference.",
                ))
    if problems:
        return problems
    return [finding(
        "C-REF-001", "PASS", "Declared consumer references resolve.",
        "references", "abaqus-dependency-preflight-validator",
        "Preserve these identifiers through later script stages.",
    )]


def check_evidence_boundary(contract):
    evidence = contract.get("evidence", {})
    approved = evidence.get("engineering_claim") == "approved"
    gates_complete = (
        evidence.get("solver") == "complete"
        and evidence.get("physical_review") == "complete"
    )
    if approved and not gates_complete:
        return [finding(
            "C-EVIDENCE-001", "REVIEW_REQUIRED",
            "Engineering approval skips solver evidence or physical review.",
            "evidence.engineering_claim", "abaqus-output",
            "Keep the claim blocked until solver evidence and physical review are complete.",
        )]
    return [finding(
        "C-EVIDENCE-001", "PASS", "The declared claim respects the evidence gates.",
        "evidence", "abaqus-output",
        "Continue to keep static, solver, physical, and claim stages separate.",
    )]
```

```python
DISCLAIMER = (
    "Static contract review only. No Abaqus solver execution or physical "
    "engineering validation was performed."
)


def build_report(contract_path, contract, findings):
    return AuditReport(
        schema_version="1.0",
        runner_version=__version__,
        scenario_id=str(contract.get("scenario_id", contract_path.stem)),
        input_digest=input_digest(contract_path),
        findings=tuple(findings),
    )


def report_payload(report):
    return {
        "schema_version": report.schema_version,
        "runner_version": report.runner_version,
        "scenario_id": report.scenario_id,
        "input_digest": report.input_digest,
        "summary": report.summary(),
        "findings": [dataclasses.asdict(item) for item in report.findings],
        "boundary": DISCLAIMER,
    }


def render_json(report):
    return json.dumps(report_payload(report), indent=2, sort_keys=True) + "\n"
```

Use one safe writer so repeat runs accept identical deterministic content but
never replace a different existing report:

```python
def render_markdown(report):
    lines = [
        f"# Audit report: {report.scenario_id}", "",
        f"Input SHA-256: `{report.input_digest}`", "",
        "| Status | Count |", "|---|---:|",
    ]
    lines.extend(f"| {status} | {count} |" for status, count in report.summary().items())
    lines.extend(["", "## Findings", ""])
    for item in report.findings:
        lines.extend([
            f"### {item.code}: {item.status}", "",
            item.message, "", f"- Location: `{item.location}`",
            f"- Related skill: `{item.skill}`", f"- Next action: {item.next_action}", "",
        ])
    lines.extend(["## Boundary", "", DISCLAIMER, ""])
    return "\n".join(lines)


def write_reports(report, output_dir):
    json_path = output_dir / "report.json"
    markdown_path = output_dir / "report.md"
    planned = ((json_path, render_json(report)), (markdown_path, render_markdown(report)))
    for path, content in planned:
        if path.exists() and path.read_text(encoding="utf-8") != content:
            raise FileExistsError(f"refusing to replace non-identical report: {path}")
    output_dir.mkdir(parents=True, exist_ok=True)
    for path, content in planned:
        if not path.exists():
            path.write_text(content, encoding="utf-8")
    return json_path, markdown_path
```

```python
@dataclass(frozen=True)
class InstallPlan:
    skill_name: str
    source: Path
    destination: Path
    collision: bool


def execute_install(plan: InstallPlan, apply: bool) -> bool:
    if plan.destination.exists():
        raise FileExistsError(f"destination already exists: {plan.destination}")
    if not apply:
        return False
    plan.destination.parent.mkdir(parents=True, exist_ok=True)
    shutil.copytree(plan.source, plan.destination)
    return True
```

The CLI prints source and destination for both dry-run and apply modes. It never
