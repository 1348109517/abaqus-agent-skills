## Action B: proposed public post

Proposed title:

> A deterministic static preflight for Abaqus automation contracts (open-source synthetic demo)

Proposed body:

> I maintain **Abaqus Agent Skills**, an early-stage Apache-2.0 project that
> packages reusable review guidance for Abaqus automation. I built the v0.3.0
> demo around a recurring scripting problem: a model can be internally
> inconsistent long before a solver run tells us anything useful. A renamed
> region, an unresolved material reference, or an engineering claim that skips
> its evidence gates should be visible during preflight.
>
> The demo reads a small synthetic JSON contract and performs eight deterministic
> checks covering units, names, references, steps, mesh intent, output requests,
> and evidence state. It uses only the Python standard library, so the workflow
> can be inspected without Abaqus, a license, or private project data:
>
> ```bash
> git clone https://github.com/1348109517/abaqus-agent-skills.git
> cd abaqus-agent-skills
> git checkout v0.3.0
> python scripts/run_demo.py --scenario naming-drift
> ```
>
> The reproduced summary is:
>
> ```text
> PASS: 7
> WARNING: 0
> REVIEW_REQUIRED: 1
> ```
>
> `C-REF-001` identifies that the `Gravity` load refers to
> `ExcavationFaceRenamed`, which is not a declared region. A second scenario,
> `evidence-overreach`, reports `C-EVIDENCE-001` when an engineering claim is
> marked approved while solver and physical-review gates remain incomplete.
> Reports are written as both JSON and Markdown and contain no runtime timestamp
> by default, which makes repeated synthetic runs deterministic.
>
> This is deliberately a **static contract review**, not an Abaqus solver,
> constitutive-model validator, ODB interpretation, or proof of physical
> correctness. A `PASS` means only that one declared static check passed.
>
> Release and demo guide:
> <https://github.com/1348109517/abaqus-agent-skills/releases/tag/v0.3.0>
>
> I would value engineering feedback on the contract fields and evidence gates.
> If you can reproduce a defect, please open an issue; proposals for additional
> synthetic failure cases are also welcome.
>
> Abaqus is a trademark of Dassault Systemes or its affiliates. This independent
> project is not affiliated with or endorsed by Dassault Systemes or SIMULIA.
