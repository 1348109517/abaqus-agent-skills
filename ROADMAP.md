# Roadmap

Future work is evidence-led and has no promised dates.

## Completed context

- v0.3.0 includes a synthetic cross-skill contract demo that exercises
  geometry, mesh, interaction, field, output, and export contracts together.

## Future scope

- Add optional JSON metadata templates for provenance and release compatibility.
- Add more application-level tests for selection-matrix and quickstart paths.
- Consider solver-specific adapters or claims only after independently verified
  solver evidence, physical review, and a clean-room implementation with tests.

Candidates require either verified reusable licensing or an independently
planned clean-room implementation with tests.
