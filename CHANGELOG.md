# Changelog

## 0.3.0 - 2026-08-13

- Add a deterministic, standard-library-only CLI demo for synthetic
  tunnel-and-soil contract audits with complete, naming-drift, and
  evidence-overreach scenarios.
- Render auditable Markdown and JSON reports with explicit boundaries between
  static checks, solver evidence, physical review, and engineering claims.
- Add a dry-run-by-default skill installer with explicit targets and collision
  checks.
- Add bilingual quickstart, architecture, demo, compatibility, contribution,
  and community-launch documentation for the public workflow.

## 0.2.0 - 2026-08-11

- Expand the public catalog from ten to seventeen clean-room Abaqus workflow skills.
- Add API documentation, controlled export, fields, geometry, interactions, mesh, and output guidance.
- Add a release-compatibility boundary for Abaqus/CAE, embedded Python, abqpy, read-only checks, and dry-runs.
- Extend the English and Chinese indexes and selection matrix.

## 0.1.0 - 2026-08-10

- Publish ten clean-room Abaqus workflow skills.
- Add bilingual overview, selection, architecture, examples, and quickstart documentation.
- Add repository structure, link, sensitive-text, and file-size validation.
